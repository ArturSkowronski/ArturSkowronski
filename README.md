## About This Repository

Welcome! I'm the Head of Java & Kotlin Engineering at VirtusLab and the curator of JVM Weekly newsletter. This repository is where I share my conference talks, presentations, and technical deep-dives into the JVM ecosystem.

Whether you're interested in cutting-edge AI integration with the JVM, performance optimization techniques, or just curious about building a NES emulator in Kotlin, you'll find content here that explores the ever-evolving world of JVM technologies.
